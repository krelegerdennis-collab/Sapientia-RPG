# PLACEHOLDER - replaced by RPG ART

Alles in deze map is PLACEHOLDER-art voor het Donker Woud (WM1 T2), 16x16 per tegel (frames naast elkaar).
Gemaakt door `tools/woud_tegels_placeholders.py`: groepskleur + arcering, witte rand = beloopbaar,
magenta rand = massief, half doorzichtig = overlay (boven de speler).

Vervangen door RPG ART: teken de tegel (zie `docs/art/woud_tiles_16px.md`), zet hem bv. in
`assets/tiles/woud16/<naam>.png` en pas in `data/woud_tegels.json` alleen het `"file"` van die tegel aan.
Geen code-wijziging nodig. Daarna mag het placeholder-bestand weg.
