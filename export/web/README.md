# SAPIENTIA in de browser

Web-build van `main` (`bfff094`), gemaakt met Godot 4.7.2.
Threads staan uit. GitHub Pages kan de COOP/COEP-headers niet zetten
die een build mét threads nodig heeft. De touch-knoppen uit het spel
(stuurknop links, A en B rechts) zitten in deze build.

## Spelen op je telefoon

https://krelegerdennis-collab.github.io/Sapientia-RPG/

Na een nieuwe publicatie: hard verversen (Safari: het tabblad sluiten en opnieuw
openen; Chrome: het menu, dan verversen). De browser bewaart de oude `index.pck`.

De eerste tik ergens op het scherm (ook Doorgaan of Nieuw spel) zet het geluid aan.
Tot die tik staat er **Tik voor geluid**. Houd de telefoon liggend.

Deze build is de huidige `main`. De branch `cursor/dungeon100-samengevoegd-29ec`
bestond nog niet. Wat nog alleen op de losse dungeon100-branches staat, zit
hier niet in. Als die merge op `main` staat, vraag om een nieuwe web-build.
