# Botsingen: Worldbuilder vs game (v0.17 = canon)
*8 okt 2026. Bronnen: PROLOOG/ACT1_LORE, README, HANDOFF_WOUD, game_data/story_data.*

1. **Noor: herkomst.** Game nu: dorpsmeisje uit Esdoorn (bij Marit), kent Dennis en de Oude Man niet.
   Worldbuilder: Noor Zeldenrust, wees uit Huize Zeldenrust in Brandwijk, leerling van Ewout.
   → Game houden; Brandwijk hooguit later als geheim verleden.
2. **Oude Man.** Game nu: naamloos, "Opa", kent de namen van Noor en Lotte NIET, leeft (gewond).
   Worldbuilder: Ewout Valk, ±340 jaar, voogd, leidde beide meiden op, sterft in Act 3.
   → Game houden; "Ewout Valk" eventueel als late onthulling.
3. **Dennis: afkomst.** Game nu: kleinzoon/pupil van Opa, gewone jongen.
   Worldbuilder: 17 jaar, Proefpersoon H-6 uit Archief 4, draagt de Hanger (= de Sleutel).
   → Combineren: Hanger overnemen, H-6-twist pas later beslissen.
4. **Noor en Lotte: leeftijd, uiterlijk, klasse.** Game nu: Noor jong, kastanje paardenstaart; Lotte blond met vlecht, Priester.
   Worldbuilder: Noor 29, kort zwart haar; Lotte 24, kastanjebruin, "Luisteraarster".
   → Game houden (art is klaar); "Luisteraarster" kan als bijnaam/skill.
5. **Plaatsen.** Game nu: Wachtershuis → Esdoorn → Donker Woud; Wilgendal komt later.
   Worldbuilder: Wachtershuis → Stilwoud → Hazelbrug → Ruigveen; geen Esdoorn/Wilgendal/Donker Woud.
   → Game houden; lore-namen alleen voor latere regio's (Wilgendal ≈ Hazelbrug?).
6. **Wanneer Noor meedoet.** Game nu: direct na de Golem, na de Wortelkoning in het Donker Woud.
   Worldbuilder: Act 2 in Ruigveen (±L7), Lotte in Slakkenburg (±L8).
   → Game houden; Lottes plek is nog vrij en Slakkenburg kan.
7. **Golem-baas.** Game nu: "Het Kennis-Beest", van boeken/code, roze kern, zwak voor vuur.
   Worldbuilder: "Kustos", mechanisch, zwak voor bliksem/water.
   → Game houden; "Kustos" eventueel als eigennaam.
8. **Monsters Archief 1.** Game nu: Mosslijm, Moskonijn, Papiergeest, Glitchmot, Mech. Wachter.
   Worldbuilder: Inktwurm, Mechanische Wachter, Dwalende Pagina.
   → Combineren: Mech. Wachter = dezelfde, Papiergeest ≈ Pagina; Inktwurm erbij.
9. **Magie.** Game nu: roze vonken, glitch, roze kern, Kernkracht.
   Worldbuilder: "de Stroom" (reageert op gevoel); Sapientia maakt er Zwarte Stroom van.
   → Combineren: roze = de Stroom, glitch = Sapientia's invloed.
10. **Stats en levels.** Game nu: atk/def/mag/mdef/agi; Golem op ±Lv 10, Woud Lv 10-13.
   Worldbuilder: aanval/verdediging/magie/mag. verdediging/snelheid; L1-40, Archief 1 = L1-5.
   → Game houden; JSON alleen via converter + herbalanceren.
11. **Namen van items en NPC's.** Game nu: Kort zwaard, Vonkzwaard, Geneeskrachtig kruid, Oude Bram (Esdoorn).
   Worldbuilder/Design: Oefenzwaard van de Wachter, Kruidenthee, Vonkkling, Bram Holt.
   → Game houden; Vonkkling en Bram Holt hernoemen bij inbouw.
