# Handoffs (RPG CODE / RPG ART)

Historische en actuele **overdrachtsdocumenten** per feature-patch: besluiten, bestandslijsten,
testcommando's en screenshot-paden. Ze beschrijven vaak een oude scratch-werkmap; die paden zitten
niet in git.

- Nieuw handoff-bestand: `docs/handoff/HANDOFF_<onderwerp>.md`
- Review-tickets en sprintplan: o.a. `HANDOFF_review_2026-11.md`
- Agent-regels: `AGENTS.md`, flow: `../WORKFLOW.md`
